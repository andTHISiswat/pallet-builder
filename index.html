PALLET BUILDER

Built by: Tyler Wilson

The free pallet building program: from pick sheet to pallet build sheet

Enter a pick sheet, pick list or PO. Pallet Builder tells you how many pallets you need and how to stack each one, layer by layer: which boxes, which way they face, and where the plywood goes.

Download for Windows Try it in your browser

Free · Works offline · No admin rights needed · Updates itself

What it does

Pallets needed

Counts how many pallets an order takes, keeping each under your max height and max weight.

Layer-by-layer plan

Every layer shows the part #, case count and which way each box faces, with a top-down drawing.

Keep POs together

Builds each PO in its own section, with an optional plywood split between POs.

3D view

Spin, zoom and watch the pallet build itself one layer at a time.

Upload a PO or pick list

Excel or CSV with PO #, part # and qty. Match columns reads files from other systems.

Read a picture

Snap a photo of a pick sheet or box label and it reads the part numbers and quantities.

Box catalog

Save case sizes, weight per case and units per case. Upload from Excel or add one at a time, in tabs.

Print and export

Print build sheets for the floor, or export a pallet manifest and summary to CSV or Excel with pallet IDs.

Save, open, back up

Save builds in folders by PO or order #, and back everything up to one file.

See the pallet before you build it

The 3D view stacks the pallet one layer at a time, so you can check the build before you pull a single case. Turn it 90°, look top down, or press Build it to watch it go together.

A build sheet anyone can follow

Each pallet lists what to pull for every PO, then walks through each layer: how many cases, which side faces which way on a 40×48 (or any size) pallet, and when to lay a sheet of plywood. Set your own pallet size, max height, deck height, max weight and overhang.

Install on Windows

  1. Download Pallet-Builder-Clean-Installer.zip.
  2. Unzip it and run the installer. No admin rights needed.
  3. Open Pallet Builder from the shortcut. Press How to use for a 4-minute demo video, or Try the 45-PO test to see an example order.

Installed copies update themselves and keep your saved builds, parts, PO #s, folders and tabs.
